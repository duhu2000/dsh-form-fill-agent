# 提示词向导映射体验收口

2026-09-09，本轮为待发布前端修改，基线主包 0.2.16。

参考清洗补全的向导内 MappingPicker：原列映射在第二步完成，确认后自动进入填写范围。本侧复用工作台同一组 DOM 控件和配置接口，不复制清洗端新增输出列逻辑。

- 第二步可直接选择推荐、搜索维度、确认映射；共享自动通过、待确认、未匹配和跳过状态。
- 应用映射并继续后进入第三步。未应用的修改不能通过顶部步骤按钮绕过。
- 第三步自动纳入已确认字段，仅在需要减少范围时调整。
- 最后展示工作表、字段和待补空位置数量；明细折叠且最多展示 200 个位置，完整计划仍由任务保存。保留列需要明确确认，禁用原因在向导内展示。
- 关闭向导时把共享控件恢复到工作台；刷新恢复已保存映射。草稿回填沿用现有 Host 协议，不在向导中查询。

验证：`npm run check`（111 项测试及四包检查）、`scripts/configuration-ui-smoke.mjs`、新增 `scripts/wizard-mapping-smoke.mjs`。新增用例覆盖 60 行合成 XLSX、地址候选确认、120 个位置的简短描述、向导关闭及刷新恢复、深浅色 390/900 像素布局。

本轮未改 core、Provider 或共享字段目录，无共享包发布需求。建议主包后续发布 0.2.17；此文件不表示已发布或已更新本机运行中的插件。

`scripts/native-ui-smoke.mjs` 已按第二步应用映射后的 revision 验证通过，覆盖原生 React 测试宿主中的草稿追加/替换、面板恢复与普通会话隔离；这是测试宿主契约回归，不代表真实 DSH 模型端到端验收。
