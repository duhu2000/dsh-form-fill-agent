# 多位置映射、向导原表预览与进度验收

基线：主包 0.2.20。建议下一主包版本 0.2.21；Provider 0.2.2、core 0.2.10、contracts 0.1.0 无需变更。

## 原因与修改

- UI 原来只提交手动修改的映射。一个自动匹配列与一个手选重复列组合时，core 仍认为重复位置未全部确认。现在应用映射保存当前全部明确选择，按 sheet/column 区分位置；核心仍检查企业输入定位冲突，重复输出位置可共享同一字段并复用查询。
- 向导原来只挂载字段设置组件，没有挂载完整表格。现在移入同一 grid 组件，第二步默认展开，保留全量分页、横向列分页、搜索与原表/结果视图；关闭向导归还工作台。
- 新 task-presentation 在服务端为当前任务和历史任务生成相同名称、处理状态与分类统计。UUID 留在展开详情。企业数按已识别的非空输入主体组合去重，创建时间使用 Asia/Shanghai。
- 进度按实际回调查询计划项显示；未拿到总数时显示 0，不编造进度。正常执行结束为 100%，取消/中断/失败保留实际进度。绿色只表示处理结束；另显示待核验、失败数量。
- no-data 与明确排除、公式/格式保护记录移至结果说明；异常表保留核验与错误项目。审计清单仍包含所有保留原因。
- 调整映射、范围或主体后清空上一轮进度，避免旧完成状态残留。

## 验证

- `npm run check`：118 项测试与四包打包检查通过。
- `scripts/wizard-mapping-smoke.mjs`：60 个合成主体，10 列；自动注册资本与推荐重复列同时保存为独立位置，去重范围 8 个字段，对应 540 个补空位置。向导默认展开的 grid 显示多行，而非只有表头。
- 真实本地服务配合延迟合成 Provider，验证运行中切到主体核验，结束后进入预览并显示 100%；当前与历史名称一致，刷新后映射保持。
- 深浅色 × 390/900 像素视口交互和横向溢出检查；截图在 `/tmp/ff-inline-mapping-*.png`、`/tmp/ff-progress-*.png`。
- `test/task-presentation.test.mjs` 覆盖未披露、待核验、调用失败、整体失败、取消和重新配置状态；原有 `test/mapping-positions.test.mjs` 验证同字段多位置写回、查询去重、非空/0/false/公式及 OOXML 保护。

只使用合成数据、随机本地端口；没有调用真实企查查、修改用户 DSH 配置或重启服务。此记录为代码验收，不代表 npm 已发布。
