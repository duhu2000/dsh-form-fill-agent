# AI 填表：历史、映射搜索与真实进度验收

日期：2026-09-13；目标主包：0.2.28。

## 差异与实施顺序

参考数据清洗补全任务及仓库当前 main 2424c97；今天仍在进行的开发不作为已发布事实。

1. 原历史列表可把其他会话任务 ID 写入当前页，详情仅检查 owner。改为只读元数据，当前恢复、详情、下载、修改和工具执行检查来源 Session。
2. 原映射搜索仅命中字段。增加维度命中全部子字段，组合输入结束后再过滤，筛选外已选字段继续保留。
3. 原进度缺少当前实际动作、查询结果分类、耗时。记录实际调用和完成事件；已有百分比仍只表达处理进度。
4. 原 Home 级持久化不能证明 Profile 隔离。通过安装路径祖先的私有 dsh.profile 清单识别 Profile，不能识别时内存降级；不自动归属旧任务。

## 边界与未覆盖项

- 同访问凭据可见历史；不扩大到不同凭据或不同 Profile。历史不返回文件字节、字段内容或凭据。
- 没有公开来源会话切换能力或来源会话不可见时明确降级。历史元数据不具备跨会话重新执行能力。
- 本轮未对四智能体同时安装做新的端到端验收；不能将清洗侧或既往总账结果算作本侧此次通过。
- 未放宽实际控制人分页完整性判断，缺少证据仍保持待核验。
- 旧 Home 存储未迁移；管理员可在确认归属后通过显式 taskDirectory 使用原目录，不自动复制原表。
- 共享包无需变更或发布，Provider 保持 qcc-field-contracts 0.1.0；工作区已有 0.2.0 不纳入发布链。
