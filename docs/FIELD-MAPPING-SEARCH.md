# 字段映射搜索与推荐

- 明确显示已有精确名称/别名自动映射。未匹配项提示人工选择或保留不填写。
- 未匹配字段按原表名称提供最多四个候选，需点击确认；不将近似匹配静默应用。例如“联系电话”可以推荐“首选联系电话”和“开票联系电话”。
- 每行提供目标字段关键词过滤（名称、字段 ID、别名；支持多关键词和顺序字符模糊匹配）及来源目录维度筛选。
- 筛选不会更改已选字段；筛选外的当前字段单独标注保留。零结果提示更换关键词或维度。
- 顶部搜索仅筛选原表列名，与每行目标字段搜索分开。
- 维度来自 Provider 公开目录，转换历史别名 ID；没有分组的字段进入“其他字段”。不改 Provider 或共享内核行为。

验证：98 项测试与打包通过；隔离浏览器验证推荐不自动应用、电话歧义候选、模糊搜索、维度筛选、筛选保留选择、应用并刷新恢复、原表名称过滤、工商别名分组、深浅色窄屏及原有候选/取消重试回归。
