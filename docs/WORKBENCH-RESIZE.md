# 工作台连续调宽验收

依据共享交互规范 1.3.0 / UX-39 及原型左边缘分隔条设计。招投标使用 Better Sidebar 的会话级工作台服务；AI填表保留自有面板，提供等效交互，不强制安装第三方插件。

## 已实现

- 8px 命中区、3px 企查查蓝悬停/聚焦线；指针捕获，向左增宽、向右减宽。
- 可访问 separator、实时宽度读数；方向键 16px、Shift 48px、Home/End、双击默认宽度。
- 面板下限 320px；按中央容器左边缘到窗口右边缘的可用区域计算，上限扣除中央 420px。宿主区域不足 740px 或窗口不宽于 760px 时全屏并隐藏分隔条。
- 展开为最大宽度预设，收起恢复手动宽度；手动拖动退出展开。
- Escape、pointercancel、失焦取消并恢复拖前值；关闭、业务切换、卸载清理监听及中央让位。
- 当前客户端生命周期内保留偏好，不跨刷新存储，不修改任务和草稿。缩窗约束有效值，放大恢复偏好。
- 最窄面板标题操作区换行，关闭按钮保持可达。

## 验证

- scripts/native-ui-smoke.mjs：实际鼠标拖拽、键盘/Home/End、复位、Escape/失焦/pointercancel、展开恢复、关闭重开、缩窗恢复、280px 宿主左栏占位、中央保留 420px、窄屏和深浅色检查通过；原有草稿、任务恢复及普通会话流程通过。
