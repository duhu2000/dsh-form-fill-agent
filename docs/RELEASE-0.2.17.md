# 0.2.17

提示词向导现在直接提供与工作台相同的字段映射控件，支持推荐候选、搜索与确认状态。应用映射后进入填写范围，已确认字段自动纳入，无需重复选择。

确认描述改为数量摘要，位置明细折叠展示。未应用的映射不能通过顶部步骤跳过；关闭向导和刷新后保留已保存设置。保留草稿编辑、用户发送和结果确认流程。

验证：111 项测试、四包检查、配置和导出浏览器回归、向导合成 XLSX 回归、深浅色窄屏及原生 React Host 契约回归。真实模型端到端不在此次验收范围。

仅发布主包 0.2.17，依赖保持 core 0.2.10、Provider 0.2.1、字段契约 0.1.0。从稳定基线建立 release/0.2.17 分支，不包含主线尚未接入的共享字段包 0.2.0。
