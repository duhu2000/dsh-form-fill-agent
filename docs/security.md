# 文件与运行边界

输入文件视为不可信。ZIP 先验中央目录再有界解压；校验 CRC、本地头一致性、重叠条目、目录路径、重复路径、压缩方式与实际解压长度。禁止路径穿越、宏、加密、外部链接和未知 ZIP 部件。XML 禁止 DTD/ENTITY，最大嵌套 128。

限制：输入/输出 8 MiB，解压总量 32 MiB，单条目 8 MiB，256 ZIP 条目，压缩比 200，16 工作表，10,000 行，128 列，100,000 已存在单元格。

## Excel 支持矩阵

| 能力 | 当前策略（alpha.8 起） |
|---|---|
| 简单多表、标题行、非首行表头、同义表头 | 支持；疑似多个表头时需先拆分 |
| 字体、填充、数字格式、行高、列宽 | 保留原 XML；三套 fixture 和独立 openpyxl/XLSX 反读验证 |
| 标题合并 | 原样保留；记录或表头映射位置合并时不填写 |
| 隐藏表/行/列 | 原样保留，不填隐藏区 |
| 冻结窗格、筛选 | 原样保留并验证 |
| 真空白、纯空白字符串 | 默认可填写；已有非空值永不覆盖 |
| 占位符、错误值、未知字段、多个主体候选 | 列入未完成项；不自行猜测 |
| 普通内部公式及缓存 | 支持白名单函数；保留公式，填写后清除公式缓存并要求 Excel 完整重算，不在插件中计算 |
| 固定文本内嵌下拉验证 | alpha.5 支持，验证 XML 原样保留；候选值必须满足覆盖该格的所有下拉选项 |
| 固定区域/固定命名区域下拉、基础条件格式、普通表格对象 | 支持受限结构，原 XML 保留；下拉来源、表头及汇总行不填写 |
| 动态区域、共享/数组/未知函数、计算表格列、扩展条件格式、批注、超链接、图片、图表 | 明确拒绝相关结构或 ZIP 部件 |
| 外部链接、宏、保护、加密文件 | 明确拒绝 |
| 日期、信用代码等事实值 | 作为文本写入，保留前导零；mock 信用代码明确标为 SYNTHETIC，不是假装有效的真实代码 |

写回仅填写已确认单元格；存在公式时还会移除公式缓存并更新工作簿计算标记。未编辑 ZIP entry 的解压后字节保持一致；ZIP 压缩字节不承诺相同。原文件不覆盖，文件输出目录独占创建。输入 hash、planId、changeSetId 绑定预览；摘要用于一致性检查，不是数字签名。

字段配置和主体确认受 owner/revision 与任务状态校验；只选择受支持字段，候选 ID 必须来自当前预览，不自动选择。人工主体值仅用于查询，不覆盖原表名称。schema 5 保存设置、字段范围、完整候选及执行检查点，读取 schema 1–5；旧版本不能读取 schema 5，回退请使用升级前目录副本或新目录。

Provider 值必须有来源、获取时间及足够置信度；公式前缀和非法 XML 控制字符阻断。UI 使用 textContent 显示不可信内容。事实值没有 LLM 生成路径。

真实 QCC Provider 接受显式授权 transport；DSH 仅通过 form_fill_enrich 的 Agent-owned 上下文嵌套调用工商/候选检索工具，不读取 OAuth 或凭据。网页上传/确认不执行远端工具。alpha.9 按运行时工具可用性扩展企业、经营和风控域；域外工具不可代理。先核验身份，再读取所选数据。风险仅输出原始计数或确定性维度摘要，不生成风险评级，不跨维度求和。投影来源路径含 /projection/，与直接字段区别标示；未知目录变化阻断该组填写。真实响应只归一化请求字段、来源及获取时间，不持久化原始 MCP 响应。DSH 和浏览器验证使用隔离进程、合成数据与非 43120 端口。Web 校验 Host/Origin，跨站写入拒绝；带 owner 的任务同时校验浏览器随机 owner（256 位）和任务 ID；任务历史仅列相同 owner 的任务。旧无 owner 任务仍兼容随机 ID bearer 访问，不进入新 owner 历史。sessionId 是导航范围，不代替授权；修改另需 revision 防冲突。不提供任意文件读取接口。

取消会终止本地后续查询并发出 AbortSignal，不能保证远端撤销。每个主体调用后保存检查点；重启把运行中任务标为 interrupted。重试保留成功值，只查询失败、取消或未执行字段；最后一次远端完成而本地尚未持久化的请求可能重试，无法承诺远端恰好一次。

任务文件为原输入及归一化预览，不是匿名数据；持久化目录须放在仓库之外，仅当前用户可读写。原子 rename 防止半写文件，进程锁拒绝并行写入，启动时校验计划摘要和输入匹配，已确认输出可重建。此机制不提供磁盘加密，也不提供多用户服务或跨设备同步。异常断电的文件系统级持久性未单独验证。
