# 0.2.5

修复选择字段后列表无法直接收起的问题：支持双击字段、Enter 和“确认选择”，推荐选择后也自动收起。应用字段设置成功后展示下一步说明及主体核验入口，继续打开填写指令向导。修改映射后隐藏旧的下一步提示，防止未保存设置被误认为已生效。

主包 0.2.5，内核和 Provider 保持 0.2.0，不改变任务 schema 或原列填写规则。
