# 原表字段选择器

每列通过可折叠选择器集中展示推荐、模糊搜索、维度过滤和分组字段。选择器支持键盘选择、Escape 收起并恢复焦点。筛选不会清除已有选择，字段设置应用后沿用现有持久化和范围确认机制。

法定代表人及登记状态沿用精确表头匹配；地址推荐注册地址，网址推荐官方网站。多义字段由用户确认，不猜测企业值或新增原表以外的列。

截图中的“输出字段 · 已选”“任务目标”和“不参与匹配 / 补全”定位于清洗插件 lib/client.js，而非 AI填表。未删除清洗插件的独立功能；AI填表继续仅处理已映射原表字段，向导中的填写字段是原表填写范围，不是额外导出维度。

验证：99 项测试及三包打包检查；配置浏览器覆盖分组、推荐、过滤、选择恢复、七列合成表六字段导出。此改动已随 0.2.4 发布，见 [发布回执](RELEASE-0.2.4.md)。
