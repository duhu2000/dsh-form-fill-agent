# 0.2.30 — 任务提交后自动展开工作台

- Host 的公开提交接纳回调确认任务后，自动展开本会话的填写预览；草稿回填、失败提交不会自动展开。
- 同一任务与修订号只自动展开一次；后续执行事件不覆盖用户手动收起的选择。
- 后台会话、插件卸载后的回调不抢占当前界面；工作台不可用时保留既有手动入口和错误提示。
- 保留 0.2.29 的统一首页和品牌标题修复。

兼容边界：旧 Host 未提供 beginSubmission 时保留手动入口，不从草稿或轮询推断提交。

仅发布主包 dsh-form-fill-agent 0.2.30。内核 0.2.10、Provider 0.2.2 及其依赖保持不变。
