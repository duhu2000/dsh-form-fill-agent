# 表头候选推荐补充（待发布）

## 系统适配清洗侧规则

新增主包 `lib/mapping-recommendations.js`，由 HTTP 表头结构提供推荐键；向导和工作台复用同一控件显示。覆盖当前 133 个目录字段的名称/键，补充清洗侧企业标识、法定代表人、注册资金、成立日期、电话/邮箱/官网和实控人别名；清洗键 legal_rep、establish_date、reg_status、phone 分别适配本侧 legal_person、established_date、business_status、contact_preferred_phone。

行业保留国标行业/企查查行业两个候选；地址保留不同来源维度。只作推荐，不新增自动写回规则，不合并业务口径。清洗侧受益所有人、财务快照字段不在本侧当前目录，因此不提供虚假候选。

更新验收：114 项测试、四包检查通过；新增目录全覆盖、英文/中文别名、日期格式、多义及不支持字段的反例测试。浏览器继续覆盖 HTTP 返回推荐、人工确认、自动范围和刷新恢复。待发布，未更改共享包。

参考清洗补全 `mappingRecommendations` 中的别名和日期格式后缀处理，补充 AI 填表共享映射控件的候选识别：

- 企业状态 → 经营状态。
- CreditCode、Credit Code、credit_code → 统一社会信用代码（大小写、空白和分隔符归一化）。
- 核准日期 YYYY-MM-DD → 核准日期；也识别尾部 YYYY/MM/DD 及括号包裹的日期格式标注。

只处理推荐查询文本，不修改原表标题，不自动采用。候选保持待人工确认，点击采用后才转为已确认。其他语义限定不删除；仅有日期格式而没有字段名不推荐任何字段。英文信用代码作为输出使用时，仍需遵循现有企业定位/输出用途配置。

验证：111 项测试及四包检查通过；向导浏览器回归用 60 行合成表核验三项推荐、确认前留空、确认后 300 个待填位置、工作台刷新恢复和深浅色窄屏。改动仅在主包 UI 与回归脚本，未改共享内核、Provider 或目录包。本项不包含在已发布 0.2.17 中。
