# 0.2.28 — 历史、映射搜索与执行进度

- 历史仅返回同访问凭据的元数据，包含来源 Workspace / Session；不会从历史把其他会话任务绑定为当前任务。
- 详情、表格、下载、修改与执行校验来源 Session。宿主公开能力可用时打开来源会话，否则明确提示从宿主历史进入。
- 映射搜索支持维度全部子字段和字段关键词；中文输入法组合期间不重建候选，过滤保留已选值。
- 进度来自实际工具调用、完成计数和时间戳，区分有数据、零记录、无权限、失败、未知等观测结果。百分比不代表数据完整率。
- 已确认产物和任务来源不可被后续状态重绑定。

## 存储兼容性

安装在标准 DSH Profile 内时，在该 Profile 的 form-fill-tasks 目录持久化。显式 taskDirectory 配置优先；链接开发包或无法识别 Profile 的环境使用内存。旧 DSH_HOME/form-fill-tasks 保持原样，不自动迁入或归属到任何 Profile。历史继续受访问凭据和 TTL 限制，不承诺不同浏览器凭据之间可见。

主包 0.2.28；内核 0.2.10、Provider 0.2.2 不变，Provider 的共享字段契约仍为 0.1.0。本次不发布工作区中独立的共享包 0.2.0。
