# 0.2.4

字段选择器将推荐、搜索和维度过滤收进每列的展开面板，目标字段按维度分组，支持 Escape 收起并恢复焦点。法定代表人、登记状态沿用精确匹配，地址和网址提供明确推荐。

主包升级 0.2.4，内核及 Provider 保持 0.2.0。仅处理原表映射字段，不增加额外输出列；清洗插件独立功能不变。历史客户任务不会自动重填。
